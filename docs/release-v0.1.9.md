# StreamScope v0.1.9

## 问题修复

- 修复 Windows GNU 构建的桌面测试程序启动时缺少 `WebView2Loader.dll` 或应用清单导致的系统错误。
- 安装包固定使用本次构建的 `WebView2Loader.dll`，避免从旧构建目录打包不匹配的文件。

## 自动更新

- 新增基于 GitHub Release 的应用内更新检查，不需要 GitHub 账号或访问令牌。
- 启动后延迟检查更新，也可以在左侧版本区域手动检查；启动检查可由用户关闭。
- 发现新版本后显示版本号、发布时间和更新说明，由用户决定是否下载。
- 下载过程显示实际字节数和百分比，更新包通过 Tauri 签名验证后才允许安装。
- 支持暂不更新和跳过指定版本，不进行强制后台下载。

## 任务保护

- 实时流、抓包、文件或 ONVIF 分析运行期间可以检查和下载更新，但不能立即安装。
- 分析结束、报告保存后才能执行安装，避免更新过程打断任务。
- 更新检查或下载失败不会影响软件启动、离线分析和报告查看。

## 版本与安全

- 软件界面改为读取真实安装版本，不再硬编码显示旧版本。
- 更新源固定为 ZeruneLab/StreamScope 的最新正式 GitHub Release。
- 更新安装包必须通过内置公钥验证；签名错误、清单错误或下载损坏时拒绝安装。
- Windows 使用带进度提示的 passive 安装方式，需要权限提升时由系统正常确认。
- 安装范围为整台电脑；同一台 Windows 电脑上的所有用户均可启动软件、检查并下载公开 Release 的更新。安装时可能需要管理员确认。

## 首次使用说明

v0.1.8 及更早版本没有内置更新器，需要手动安装一次 v0.1.9。安装 v0.1.9 后，后续正式版本可在软件内检查、下载和安装。

## 下载与校验

- Windows x64 安装包：`StreamScope_0.1.9_x64-setup.exe`
- SHA-256：`54a6e6aae50126059d1bee8d5722ab017556f8f717981f393fd522c65b17ab3d`
- 同一 Release 附有安装包签名、`latest.json` 和 `SHA256SUMS.txt`；应用内更新会验证签名。
