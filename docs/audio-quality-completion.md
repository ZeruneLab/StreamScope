# 音频质量与音画同步实施记录

## 已完成

- RTSP、PCAP/PCAPNG 选中音频流和独立音频文件共用同一套 PCM 质量模型。
- 音频质量分析使用完整可解码样本；软件播放预览单独生成并最多保留 60 秒，两个覆盖范围不再混用。
- 保留原始声道，输出逐声道 Peak、RMS、峰均比、静音采样和近满幅采样。
- 输出 20 ms 精度的静音、削波候选区间，以及自适应窗口的 12 dB 电平突变候选，可从 UI 跳转回听。
- 输出 EBU R128 Integrated Loudness、LRA、True Peak，以及 100 ms 的 Momentary、Short-term、Integrated 响度轨迹。
- 输出平均频谱、85% 频谱滚降、48 段 Mel 时频图、动态范围和过零率。
- 双声道输出 RMS 电平差和相关系数；新增电平突变、声道失衡和立体声反相诊断规则。
- UI、JSON 和自包含 HTML 报告均展示新增证据；音频异常进入统一时间线。
- 音频可从软件导出为 WAV、MP3、M4A、FLAC 或 Ogg；异常区间可按起止时间单独导出，视频预览可导出为 MP4。
- RTSP 中每条音频轨独立生成分析、预览和完整导出源，PCAP 深度分析也保留所选音频流的原始导出源；UI 可切换轨道，HTML/JSON 报告逐轨保留结果，旧版单音轨字段继续兼容。
- 采集过程中每约 250 ms 刷新各音频轨 RTP 包数、负载量和平均码率；PCMA/PCMU 直接解码，AAC/Opus 通过内置 FFmpeg 在线解码，均显示真实 PCM Peak/RMS 和滚动波形。
- JSON、HTML 与 UI 保存 RTP 包/序号、Access Unit、编码字节区间和 PCM 采样区间映射；PCM 异常区间可反查抓包包号与 RTP Sequence。
- RTSP 各轨媒体负载边收边写 `rtsp-spool`；PCAP 媒体负载完整流式落盘，整理和深度分析只加载有界窗口。
- 命令行新增 `analyze --audio <文件>`，用于无 UI 的回归与批处理。

## 音画同步边界

音画同步同时保留两类证据：同一 RTCP CNAME 下 Sender Report 的 RTP/NTP 时钟映射，以及深入分析时对明显闪光上升沿和蜂鸣/脉冲起点的内容事件配对。内容结果输出偏移、事件数量、测量误差、置信度和漂移；没有可配对测试事件时明确保持“证据不足”，不会用普通画面或节目声音伪造内容级结论。

## 明确限制

- THD、SNR、SNDR 没有作为普通节目内容的确定性指标。THD 只适用于已知测试音，普通内容无法可靠区分信号、噪声和谐波。
- PCM 内容指标反映成功解码后的声音；解码器错误隐藏、静音填充或播放补偿可能改变观测结果，因此必须与 RTP、码流和 FFmpeg 时间线共同判断。
- Mel 时频图最多保留 96 个时间切片、48 个频带，避免长样本导致报告失控；它用于定位频谱变化，不代替声学实验室标定。
- AAC/Opus 的完整频谱、Mel、响度和异常区间仍在采集完成后生成；实时阶段提供 PCM 电平和滚动波形，不在采集线程内执行完整频谱分析。
- 内容同步针对带明显闪光与蜂鸣/脉冲的测试素材；普通自然视频的口型识别不在当前范围内。
- 超长任务完整负载最多流式落盘 16 GiB；结构、解码和内容分析使用每流前 32 MiB/20 万包（PCAP）或前 20 万包/有界字节窗口（RTSP），报告会明确标记分析窗口限制。
- 软件播放预览最多保留 60 秒；异常区间导出优先使用对应音轨的完整保留源，因此可以导出预览范围之外、但仍位于本次保留样本内的区间。

## 已执行验证

- 音频、FFmpeg、分析器、诊断和报告单元测试。
- FFmpeg 合成 AAC 与 Opus 在线解码回归：采集未结束时均能产出真实 PCM 波形。
- 合成闪光/蜂鸣事件回归：可恢复已知 120 ms 内容偏移并输出事件对。
- 61 秒 WAV 回归：质量覆盖 61 秒，播放预览小于完整输入，证明两条链路独立。
- 6 秒双声道反相信号端到端回归：报告状态 `Completed`，相关系数 `-1.000`，触发 `AUD-048`。
- 全工作区 Clippy（warnings as errors）和 React/TypeScript 生产构建。
