# 核心插件版界面修整（2026-10-08）

修正核心插件版使用浏览器默认控件、导航名称过长、参数和结果混排的问题，沿用原版深色侧栏、青蓝配色、白色卡片和分步骤面板。仅修改宿主 React 展示及限定范围的样式，不修改分析器、进程协议、插件权限、签名或安装逻辑。

- 输入、下拉、文件选择、复选框和按钮统一宿主样式；文件路径占整行，其他参数按网格排列。
- 参数与结果分为 01/02 面板；保留任务取消、进度、报告编号和原始数据查看，执行期间禁用参数编辑。
- 动态导航仍由启用插件提供；官方入口使用短显示名和图标，多动作插件的附加入口缩进，第三方入口保留声明标题。标题去掉冗余“（插件）”，滚动栏使用细轨道，当前入口自动保持可见。
- 插件管理使用卡片网格、版本/状态标签和明确的卸载按钮；历史报告使用列表行。
- 表格、语法树、HEX、播放器和下载控件沿用宿主结果组件，增加限定在插件结果内的样式，不修改旧版分析页面。

验证：`npm run build`、`npm run build:core`、`node scripts/verify-plugin-components.mjs`、`node scripts/verify-plugin-ui-layout.mjs`、`node scripts/core-host.mjs package` 和 `node scripts/verify-core-host.mjs` 均通过。14 个插件入口的参数渲染通过，1280/1000 宽度没有页面横向溢出，模拟执行前后控件禁用/恢复、表格、QP 叠加及 HEX 布局通过。后台布局验证使用全新临时 Edge headless 配置和本地模拟宿主数据，不连接用户的浏览器或桌面，不执行真实分析、网络测试或安装操作。截图位于 `target/ui-preview/`，用于视觉检查；这不是生产样本端到端验收。
