- 插件目标、与已有插件的边界：`<填写>`
- 输入类型与样本：`<填写>`
- 与其他插件的联动动作及来源产物类型：`<填写>`
- 输出数据、证据及失败场景：`<填写>`
- 宿主组件（表单/选项/表格/图表/时间线/媒体/帧覆盖/HEX/语法树/另存/报告）：`<填写>`
- 依赖插件及版本范围：`<填写>`
- 宿主权限与网络/文件范围：`<填写>`
- 目标平台和架构：`<填写>`
- 发布者 ID、公钥指纹和许可证：`<填写>`

遵循 `docs/plugin-spec.md` 与 `schemas/plugin-manifest.schema.json`。只能调用公开 Host API；不能依赖 StreamScope 私有 crate、硬编码安装或报告目录、加载第三方页面脚本、记录凭据或将大媒体逐包塞进 JSON。对原生 EXE 不得声称有操作系统沙箱。

需要联合分析时使用规范中的 `actions` / `hostActions`，以来源报告的产物 ID 交接文件并保留流上下文；不要求用户重新选择 PCAP，不把抓包文件直接交给媒体解码器，不以转码预览替代原始码流证据。由宿主验证目标插件、动作和产物；填充参数之后由用户执行，不能因页面导航自动发送网络请求。分别测试多路不串流、缺少插件、产物被篡改、切换页面和来源报告保留。

交付完整 `manifest.json`、声明式 UI、源码、单元及端到端测试、异常/超时/取消处理、打包和签名说明。生成代码或未签名 `.ssp` **不得标记为可安装**；必须由发布者在可信环境签名，宿主再验证完整包与指纹。明确列出未实现项和与现有分析功能的等价回归结果。
